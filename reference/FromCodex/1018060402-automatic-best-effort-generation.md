# 自动尽力生成与任务状态显示

时间：2026-10-18 06:04，Asia/Shanghai。

## 最终行为

根据用户最新要求，Web 自动流程以“尽力为全部家具生成”为目标，图片质量、遮挡和截断检查不再直接阻止任务。

房间导入或列表加载后，后台依次使用优选的 RGB-D 分离图、可用原裁剪或投影关键帧裁剪、邻近可读关键帧。优选失败自动降级，不弹出补拍确认，也不依赖代理逐件选择或触发任务。备用图片会保留质量提示，生成结果仍按扫描真实尺寸缩放并原位回填。

修正靠近相机的大型家具候选投影：使用箱体边与近裁面的交点，避免只因部分角点在近裁面后就丢弃整件家具。门槛仍帮助优选较完整的图片，但没有优选图时会进入兜底链路。

所有可读输入都会自动尝试生成。完全没有可读图片、文件损坏、预处理异常或外部 API 实际失败仍显示真实错误，不把它们伪造为建模成功。使用备用图可能导致缺失细节、形状推断错误或邻近家具混入，不承诺任意照片生成准确模型。

## 旧状态与缓存

- 旧 `needs_review` 不再作为跳过生成的条件。房间加载、未完成流程恢复都会由后台自动处理它们。
- 使用 `best-effort-v2` 策略标记。服务更新后只对当前已选择且仍有旧拦截项的房间自动迁移；没有批量启动全部未选择房间的新任务。
- 已完成模型和进行中的任务保持复用，不因策略变化或刷新重复生成。外部失败任务及缓存损坏保护沿用既有机制，避免未经明确重试就重复付费。
- 完整高低模、纹理与原扫描目录缓存的写回方式保留。
