# App 墙地面涂装补拍与 Web 选帧配合

时间：2026-10-17 14:35，Asia/Shanghai。

## 修改原因

当前方向扫描的地板可靠照片覆盖约 14.4%。Web 已通过深度过滤和多视角取色恢复墙地面主色，但无法从没有拍到的区域还原图案。App 原先仅按固定时间采集，后端按清晰度取帧，纯色墙地面容易被家具等高纹理画面挤出选帧名额。

## App 变化

- 扫描页增加 `常规 / 墙面 / 地板` 分段选择。常规沿用原采样方式；补拍仍在同一 RoomPlan / AR 会话内，不重置房间、相机标定、深度或指南针坐标。
- 墙面自动补拍要求基本平视；地板要求向下观察。自动补拍还要求定位正常、近期平移速度低于 0.15m/s、转向速度低于 15°/s，并提示停稳或换角度。
- 同一目标成功拍摄后，需平移至少 0.15m 或改变观察方向至少 10° 才再次自动拍摄。手动相机按钮继续可用，可绕过自动采样门槛。
- 保留 300 帧与 5 分钟的原有上限，不开启额外相机会话，不锁定 RoomPlan 的曝光或白平衡。
- 新帧增加可选 `materialTarget` 和 `photometry`，后者记录曝光时长、ARKit 后处理曝光偏移及环境色温估计；无效值省略，旧数据兼容。

建议下一次完成常规扫描后，在结束前分别选墙面和地板，拍无遮挡区域，每面墙/地板尽量从至少三个不同位置或角度停稳采集。地板尤其需要向下看，水平扫过家具通常无法补足地板覆盖。这是采集建议，不是精确材质恢复的保证。

## Web 配合

后端为墙面与地板补拍分别保留最多 16 帧，剩余名额用于常规视角，总计不超过 48 帧。分组内仍考虑清晰度，并用过长曝光作辅助降权。已有扫描没有标记时保留原选帧方式，当前场景无需重建家具。

`materialTarget` 只表示拍摄意图，不替代真实平面投影与深度遮挡验证。环境色温不是已测得的白平衡，曝光偏移不是 ISO；当前没有凭这些字段强制推导真实反照率。纹理缺洞、曝光接缝与光照分离仍需后续工作，本阶段依旧采用每面统一代表色。

公开 API 依据：[ARCamera](https://developer.apple.com/documentation/arkit/arcamera)、[ARLightEstimate](https://developer.apple.com/documentation/arkit/arlightestimate)。详细字段已同步到 `app/docs/DATA_CONTRACT.md` 与前端相机类型。
