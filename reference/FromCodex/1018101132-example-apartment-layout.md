# 独立示例户型：三室一厅两卫

## 功能

- 左侧房间面板新增“生成示例户型”按钮。每次操作创建独立场景 ID，固定采用同一确定性布局，不覆盖既有扫描房间。
- 示例与扫描房间出现在同一个房间列表，可重新加载，后端重启后保留。运行数据保存在忽略的 `tmp/scans/<scene-id>/scene-manifest.json`。
- 已实际创建一份示例并设为最近场景：`1191f3cf0f644687876700db5dee0b84`。刷新 http://127.0.0.1:5173/ 即可载入，也可从房间列表选择。

## 结构

- 12m × 10m 平面，约 120㎡，统一层高 2.8m，墙厚 0.14m。
- 三间卧室、一个客厅、公共卫生间和主卧卫生间，共六个功能区域。
- 客厅分别连接三间卧室和公卫；主卧卫生间邻接主卧，唯一入口位于主卧与套卫的共墙。
- 五个内部门洞净宽 1m、净高 2.2m；另有一个 1.1m 入户门洞。门洞同时从墙面与碰撞体中扣除，保留门楣，不放置门扇。
- 生成 21 块墙板、6 块地板、6 块顶面和 23 个碰撞体。顶面底边与墙顶一致，地板基准 Y=0，Play 视高沿用 1.5m。
- `furniture: []`、`cameras: []`，不生成家具、模型、贴图或装修，不调用 Rodin、材质恢复和扫描预处理。
- 明确标记为原生示例场景，不伪造扫描或地理真北数据；房间契约仍使用米、右手系、Y 轴向上。

## 集成修复

- 切换独立房间时清除上一房间在画布中的新增家具，防止空白示例继承别的房间物品；商品资产抽屉保留。
- 修复多块旋转地板在共享边界的浮点误差：地面三角形使用极小重心坐标容差，门口接缝不再被误判为无地面。
- 示例不显示家具重建和扫描模型缓存导出按钮，后端也拒绝向这两个流程提交示例。
