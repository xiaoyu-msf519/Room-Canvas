# 家具等比例缩放

- 缩放只保留一个 Y 方向手柄，拖动时使用同一倍率改变 X/Y/Z 三个尺寸，保持当前长宽高比例和底部高度。
- 原始尺寸范围约束改为三个方向共同约束统一倍率，达到上限或下限时也不会拉伸单个方向。
- 等比例家具旁显示单一缩放倍数和当前长、宽、高（mm）；历史上已拉伸过的家具保留各方向真实原始倍率，后续拖动仍等比例改变当前形状。
- `npm run verify:scale` 通过：实际组件只有一个缩放手柄，九次交替放大/缩小、三个尺寸同倍率、上下限、松手稳定、接地、移动及 Play 保留均通过。
- `npm run build` 通过，开发服务 http://127.0.0.1:5173/ 保持运行。
