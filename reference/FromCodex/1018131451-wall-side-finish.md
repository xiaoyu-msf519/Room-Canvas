# 墙体窄侧面独立上色

- 墙体厚度方向的侧面现在是独立编辑目标，资源库选择器会列出“墙面 · 侧面”。点击墙端/侧面后应用涂装，只写入该侧面的 `editGroupId`，不改正面、反面或邻室。
- 墙几何固定拆为三组材质：侧面、正侧房间墙面、反侧房间墙面。正反墙面继续按房间独立；侧面可单独恢复原样或换材质。
- 透明 BSP 编辑碎片和 Play 实体墙均使用相同的三组材质，侧面在两种模式下保持一致。
- 对没有房间级 `wallFaces` 的旧扫描墙，也提供独立侧面目标；正反面继续共享原有扫描墙面材质。

## 验证

- `npm run verify:room-surfaces`：每房独立地板、墙面正反侧和墙体侧面目标，点击侧面得到独立 ID；侧面材质与正/反墙面互不泄漏，Edit/Play、恢复及旧涂装迁移通过。
- `npm run verify:walls`：真实扫描墙面材质数组、透明渐变和 BSP 深度排序回归通过。
- `npm run verify:example`：住宅示例 9 个空间、11 扇窗、阳台、玄关及 Edit/Play 顶面回归通过。
- `npm run build`：通过，无编译错误；已有包体积提示保留。
