# 家具缩放、删除与草稿保留

## 实现

- 选中家具后，同时显示 X/Y/Z 三个独立缩放控制点（红/绿/蓝）和白色斜向整体缩放控制点。保留原有水平移动箭头、绕 Y 轴旋转弧。
- 单轴缩放只改变对应尺寸，整体缩放保持当前比例；相对原始模型的缩放倍率与长宽高继续实时显示。家具底面保持接地，松开鼠标后提交实际尺寸。
- 选中家具后，画布下方显示带家具名称的删除按钮。Delete / Backspace 也可触发删除；所有入口先弹出二次确认，取消不改变房间。输入框、其他弹窗、拖动中及 Play 模式不响应删除快捷键。
- 删除只移除当前房间中的摆放实例；已生成模型和商品资产保留。按房间记录删除状态，后台进度轮询不会把已删除家具重新加入场景。
- 初始参考地面、网格与边线从 10m × 10m 扩大为 80m × 80m，保持 1m 主格和 0.2m 子格；空场景的拖入摆放范围同步扩大。扫描房屋自身的尺寸、结构与涂装不变。

## 已编辑房间保护

修改状态模块前先接入当前编辑会话捕获，避免热更新重新初始化已摆放家具。新增按房间保存的本地草稿 `roomcanvas-room-draft-v1:<sceneId>`，保存家具坐标、旋转、尺寸、模型地址及删除记录；切换房间、刷新后导入同一房间和后台轮询时保留编辑。

保存按钮现在实际写入本地草稿。保存发生在家具编辑提交时，不在每个三维渲染帧写入存储。

已有墙纸与地板继续使用原来的 `roomcanvas-surface-finishes-v1`，本次未修改、迁移、删除或重置该存储。不改后端户型模板、不删除扫描和模型缓存、不重新提交任何 Rodin 任务。草稿属于当前浏览器、当前站点，不是跨电脑云端同步。

## 验证

- `npm run build`：通过；仅存在既有的产物体积提示。
- `npm run verify:scale`：通过同时存在的四种缩放控制、15 次缩放拖动、单轴隔离、等比例缩放、接地、松手稳定、尺寸基准、移动和 Play 保留。
- `npm run verify:rotation`：通过 16 次旋转和 8 次移动，原有控制未回退。
- `npm run verify:furniture-editing`：通过删除确认/取消、快捷键保护、轮询不复活、房间切换/重新加载/热更新后保留家具、资产保留、墙纸地板记录不变及 80m 地面。
- `npm run verify:room-surfaces`：通过独立墙面和地板涂装回归。
- Web `http://127.0.0.1:5173/` 返回 200；后端健康检查为 `rodin: configured`。开发服务器保持运行，没有重启用户页面。
- Browser 当前没有可连接的浏览器，因此未执行桌面/手机截图及真实画布像素验证；三维拖拽使用实际 R3F + Drei 控制器做交互回归。
