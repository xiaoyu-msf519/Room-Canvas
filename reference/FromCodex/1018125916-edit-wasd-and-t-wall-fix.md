# Edit WASD 与 T 形墙交接修复

## Edit WASD

- Edit 模式现在支持 `W/S` 或上下方向键前后平移，`A/D` 或左右方向键横向平移，`Shift` 加速。
- 移动沿当前相机水平视线计算，不锁鼠标、不改变 OrbitControls 环绕和缩放；相机与 OrbitControls target 同步平移，因此继续右键/中键环绕时不会跳回旧目标。
- 输入框、下拉框编辑时不拦截键盘；离开窗口清空按键状态。Play 模式仍使用原有第一人称 WASD 和 Pointer Lock。

## T 形墙修复

- 新增墙体交接预处理：检测墙端点是否落在另一面墙的纵向内部，只有这种 T 终止关系才将终止墙向回裁到贯穿墙面；L 角不裁切，避免出现角落缺口。
- 该规则应用于 Edit BSP、透明墙片和不透明墙体绘制，保留原墙 ID、房间归属、涂装分组和碰撞数据；扫描房间也会经过同一显示几何修整。
- v4 示例生成器本身继续采用“水平墙拥有交接体、竖墙裁到水平墙面”的规则，后端逐对检查 86 块墙板无体积重叠。

## 验证

- `npm run verify:edit-camera`：实际相机移动函数验证 WASD/方向键水平运动、相机与 target 同步、Shift 加速和空输入无变化。
- `npm run verify:junctions`：当前 v4 实际生成 86 块墙板无重叠，合成 T 交接终止墙被裁切，L 角保持完整。
- `npm run verify:example`：6497 个 10cm 可行走网格点、9 个空间、门窗、阳台和顶面模式回归通过。
- `npm run verify:scan`：明确从房间列表选择真实扫描房间后，44 个墙板、地板、碰撞及家具轮询回归通过。
- `npm run verify:walls`：明确选择真实扫描房间后，透明渐变与 BSP 顺序回归通过。
- `npm run verify:scale`、`npm run verify:room-surfaces`：家具等比例缩放和房间级装修隔离通过。
- `npm run build`：通过；开发服务 http://127.0.0.1:5173/ 保持运行。
