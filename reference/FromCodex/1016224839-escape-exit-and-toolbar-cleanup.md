# Esc 退出 Play 与顶栏精简

## 改动

- 退出监听在请求 Pointer Lock 之前安装，跨模式保持注册，并从 Zustand 读取最新模式，避免事件监听切换时的空档与旧闭包。
- 捕获阶段监听 Escape keydown / keyup；浏览器吞掉按键时通过 pointerlockchange 退出。每帧额外检查锁定是否丢失，覆盖缺失或延迟的解锁事件。
- 退出时清空行走和鼠标输入，走现有编辑视角恢复逻辑；迟到的锁定请求在已退出 Edit 时释放锁定，原始位移请求失败后仅在仍处于 Play 时重试。
- 删除顶栏移动、旋转、缩放按钮及 Edit 模式的 W/E/R 快捷键监听。Play 的 WASD、鼠标环视和滚轮保留。
- 顶栏改为三列布局，Play 居中，清除已删除工具组的间隔；窄屏原框对比使用带提示的图标按钮。

## 验证

- npm run build 通过，保留现有 Three.js 包体积提示。
- 直接验证实际退出监听函数：Escape keydown、仅浏览器解锁、缺失解锁事件的逐帧兜底、keyup 兜底、迟到锁定释放、十次重复会话及监听清理。
- 本地入口 HTTP 200，开发服务器已提供移除按钮后的顶栏模块：http://127.0.0.1:5173/。
- 本轮未完成真实浏览器和物理按键验收；事件级检查不等同于设备端复现。
