# 墙体透明度渐变

- 按用户要求，在 Edit 模式给墙体透明/不透明状态加入 0.5s 渐变，目的为消除遮挡状态切换的突兀感。只插值 Three.js 材质 opacity，不增加动画依赖。
- 使用 Three.js 自带 Tween.js 的 Cubic.Out 缓出曲线，前段快速变化、末尾收缓；透明度仍在 1 与 0.18 之间，已有凹角/家具遮挡判定保持有效。
- 目标变化时记录当前实际透明度作为起点，快速转动视角可直接反向过渡，不先跳回端点。
- 将遮挡目标更新和逐帧动画推进分开，既保留相机/家具未变时的检测缓存，也能在相机停止后完成渐变。
- 渐变过程中保持透明混合、不写深度，恢复至完全不透明后再启用实心深度写入。
- 进入 Play 立即取消未完成的渐变，所有墙立刻实心。系统 prefers-reduced-motion 开启时改用更短的 0.2s 透明度过渡。

验证：`npm run verify:walls` 通过，覆盖 30/60/120fps 的 0.5s 时长、途中反向、静止后继续动画、减少动态效果设置、Play 立即恢复和既有 L 型凹角遮挡回归；`npm run build` 通过，保留原有主包体积提示。前后端 HTTP 200 并继续运行。
