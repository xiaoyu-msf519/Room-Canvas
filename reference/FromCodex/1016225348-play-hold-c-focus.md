# Play 按住 C 放大

## 改动

- 禁用 Play 模式的滚轮缩放并阻止滚轮默认行为；Edit 的 OrbitControls 滚轮缩放保持可用。
- 按住 C / KeyC 时保存 Play 当前 FOV，将 FOV 收窄至 30 度以放大画面；松开立即恢复保存的 FOV。重复 keydown 不叠加倍率，Ctrl/Meta/Alt+C 不触发。
- 放大只改变投影，不改变相机位置、朝向或 1.7m 眼高。
- 窗口失焦、标签页隐藏、锁定错误、退出 Play 和监听清理均释放临时倍率；退出时先释放倍率再恢复编辑相机，避免覆盖编辑视角。

## 验证

- npm run build 通过，TypeScript / Vite 零错误；保留现有包体积提示。
- 针对性断言通过：重复放大不叠加、释放后恢复、投影更新、位置与角度不变、不同初始 FOV 恢复、退出后编辑相机恢复。
- 本地入口 HTTP 200，已提供含 KeyC 处理的新相机模块：http://127.0.0.1:5173/。
