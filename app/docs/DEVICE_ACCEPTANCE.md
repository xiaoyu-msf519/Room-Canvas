## 第一份扫描

- [ ] 启动到扫描库，点击扫描，首次出现相机授权；拒绝后有明确状态，允许后可扫描。
- [ ] 在光线充足的单房间完成 30～60 秒扫描，包含一张桌子与一把容易辨认的椅子。
- [ ] 实时家具数量更新，关键帧数增长，手动相机按钮能追加一帧。
- [ ] 结束后处理完成，返回扫描详情，计数与列表一致。
- [ ] USDZ 能在 Quick Look 打开，房间结构与真实方向大致一致。

## 最关键的图像 / 坐标验收

- [ ] 逐个打开桌子与椅子，裁剪图方向正确，没有统一旋转 90° / 180°。
- [ ] 切到“原图框选”，绿色框覆盖相应家具，而不是相邻物品或背景。
- [ ] 至少一件家具的三个视角（若有）都可追溯到正确 frameId。
- [ ] 对尺量的一件家具比较 dimensions 的数量级和轴方向；记录误差，不宣称固定精度。
- [ ] 房间四个朝向分别扫描，避免只验证正对一面墙时恰巧对齐。
- [ ] 测试靠近画面边缘和被部分遮挡的家具，缺图与待核对标记正确。

如发生整体框偏移，导出原 JPEG、对应 frames/*.json、家具 metadata.json 和 context 图。优先检查原生图像方向、K、nativePixelToSavedPixel 以及扫描结果是否仍在同一 AR 世界空间。

## 存储、恢复与导出

- [ ] 退出 App 后重开，已完成扫描仍存在。
- [ ] 扫描时退后台，能结束或保留未完成文件；强退后不会把半成品标为已完成。
- [ ] 原始数据存在的未完成扫描可重新整理。
- [ ] 重命名后重开名称保留；删除前明确确认，取消不删除。
- [ ] 添加补充照片后，可查看，且没有混成自动裁剪或伪造相机位姿。
- [ ] ZIP 保存到“文件”或 AirDrop 到 Mac，可解压并包含逐件家具与相机记录。
- [ ] 对真实导出包运行 verify-export.py，通过文件关联检查。
- [ ] 开启飞行模式仍能完成本地扫描、处理与查看。

## 耐久与异常

- [ ] 扫描到关键帧上限后有状态提示；5 分钟时自动结束。
- [ ] 低光或定位不稳定时有提示，不把不可靠帧当作正常候选。
- [ ] 无 LiDAR 的设备显示不支持状态。
- [ ] 分别在 iPhone 和需要支持的 iPad 上检查竖屏布局、字体和分享页。
