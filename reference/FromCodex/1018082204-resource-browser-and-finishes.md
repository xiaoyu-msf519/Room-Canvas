# 资源库与墙面、地板换装交付

## 使用

- 打开 http://127.0.0.1:5173/ ，右侧新增“家具 / 墙面 / 地板”资源库，支持类别、颜色、纹理三级筛选、搜索及分页。
- 家具图片拖到下方商品图上传框后进入现有流程：确认宽、深、高（mm）→ Rodin 生成带纹理模型 → 真实尺寸缩放 → 拖入场景。点击家具缩略图也可导入。
- Edit 模式点击某面墙或地板，右侧自动切到对应资源分类；点击材质缩略图即可应用。也可通过“当前表面”下拉框准确选择表面。
- 换装后可调整整张贴图的覆盖宽、高（m），旋转贴图 90°，或恢复扫描涂装。
- Play 保留换装结果。涂装按房间 ID 保存于当前浏览器 localStorage，扫描状态轮询、切换房间和刷新页面不会清除；当前不跨设备同步。

## 数据与渲染

- 接入用户提供的 5,000 张家具图、500 张涂装贴图；墙面分类 329 项、地板分类 297 项，其中 126 项墙地两用。
- 后端从本地资源和 JSONL 来源记录建立索引，仅提供已索引的资源 ID；不公开任意文件路径、采集脚本或输入文档。
- 缩略图最大 224px，场景贴图最大 2048px，缓存位于忽略的 `tmp/catalog/`。索引按进程缓存，新增资源文件后重启编辑后端即可更新。
- 262 张贴图有可解析的整图物理覆盖尺寸；其余默认整图宽度 1m、按图像比例保留高度，可手动调整。不会把单块砖尺寸与整图覆盖尺寸混淆，也不从家具图片像素猜测家具尺寸。
- 使用资源包实际提供的颜色贴图；没有额外生成法线、金属度或粗糙度贴图。
- 同一面墙的门窗切分段统一换装，米制投影 UV 保持连续；Edit BSP 墙片和 Play 墙体使用一致坐标。
- 更换涂装不重建房间几何或 BSP；纹理副本共享图像源，独立控制铺贴比例。保留原有光照、阴影及墙体透明渐变。
