# 顶栏分栏、四季时间同步与天花板修复

## UI

顶栏现在按 Play 按钮分成三段：

- Play 左侧：日期环、时间环、位置、太阳轨迹开关。
- 中间：Play / Playing。
- Play 右侧：日夜更替、四季更替、保存场景。

日夜和四季仍为互斥状态。四季模式现在同时推进日期和时间：10 秒推进约四分之一年，并让日内时间按相同宏观速度继续变化；不再停在原时刻。日夜模式仍为 6 秒经过一天。

## 天花板与光照

天花板由平面改为带 8cm 厚度的 `extrudeGeometry`，与墙顶形成实体重叠，减少接缝漏光和 z-fighting；Play 下正常 `castShadow`/`receiveShadow`。Edit 仍低透明显示，方便观察室内。

为弥补封闭屋顶后的室内遮光，基础环境光、半球光与简化月光略微提高；太阳直射和阴影仍随真实太阳方向变化。天花板本身不额外产生室内黑块，保留室内可读性。

## 验证

- `npm run build` 通过。
- `npm run verify:solar` 通过：6 秒日夜模式推进 1 天、10 秒四季模式推进四分之一年且时间环同步推进；太阳轨迹、灯光、阴影缓存和真实扫描北向继续通过。
- `npm run verify:scan` 通过：31 面墙板、地板、1 个天花板、碰撞和 1.5m 出生点。
- `npm run verify:walls` 通过：墙面透明排序和渐变未回归。
