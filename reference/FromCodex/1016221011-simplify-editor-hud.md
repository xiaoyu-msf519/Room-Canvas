# 精简编辑器 HUD

已从 HUD 布局移除 Hierarchy 与 Inspector 的导入和渲染，编辑模式下保留顶部工具栏、常驻三维画布与底部 Asset Drawer。Play 模式沿用现有布局与控制逻辑。

Hierarchy 原用于列出房间与家具对象；Inspector 原用于查看选中对象的坐标、尺寸、校准与重建选项。当前数据为空，两者仅显示占位信息，因此按用户要求移除。组件源码保留，后续接入真实家具时可复用。

验证：`npm run build` 通过，TypeScript 与 Vite 编译零错误。忽略规则覆盖运行环境、缓存、依赖目录及敏感文件。仅暂存本次 HUD 修改与本报告，用户其他未追踪文件不提交。
