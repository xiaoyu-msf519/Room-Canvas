## 实现要点

- 不再手写重叠长墙：先提取房间边界，拆分并合并共墙，再按门窗分解墙板。水平墙占据转角/T 形交接体积，竖墙裁到其表面，仅接触、不重叠。
- 外轮廓从外墙边界求出并检查单一闭合、多凹角及面积一致性；室外凹口没有地板或顶面碰撞。
- 11 扇窗户、9 个门洞的位置根据所属房间和边界验证。阳台的三面落地玻璃与玄关无窗约束均有检查。
- 保留独立房间列表和重启后加载逻辑。每次新建实例有不同 sceneId，固定几何一致；旧示例 v1/v2/v3 读取时保留 ID 升级至 v4。
- 当前示例 `1191f3cf0f644687876700db5dee0b84` 已实际升级，房间列表仍保留原条目，furniture 为空。
