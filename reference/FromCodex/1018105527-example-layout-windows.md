# 示例户型补充窗户

- “生成示例户型”采用 v2 模板，固定生成 7 扇外窗：客厅西/南两扇、主卧南/东两扇、两间次卧北侧各一扇、套卫东侧一扇高窗。
- 普通窗台高 0.9m、窗顶高 2.3m；套卫高窗窗台 1.8m、窗顶 2.4m，采用较高雾面不透明度。公卫没有外墙，保留封闭边界，不在与卧室的共墙上开窗。
- 窗洞从真实墙板与对应墙体碰撞中扣除，保留窗台和窗楣。加入简洁窗框、透明玻璃及玻璃碰撞；玻璃不投影，可让太阳光从窗洞进入。
- 全部窗框合并成一个网格，玻璃使用共享简单材质，不使用额外折射渲染通道；不生成家具或装修贴图，`furniture` 仍为空。
- 旧版示例读取时自动升级，保留场景 ID 和列表条目，不另外创建重复房间。当前示例 `1191f3cf0f644687876700db5dee0b84` 已升级，后续点击生成也包含窗户。
