# 家具单轴水平旋转

## 交付行为

- 选中家具后，顶栏提供移动与旋转图标，分别支持 W / E 快捷键；输入框、Play Mode 和正在拖动控件时不触发工具切换。
- 旋转使用已有开源 Three.js / Drei TransformControls，配置 world 空间，仅显示绿色 Y 轴环。隐藏 X/Z 环、屏幕朝向环和自由旋转控件；不再把 hover axis 属性当作轴限制。
- 拖动和提交时将家具姿态约束为纯 Y 轴四元数，家具底面始终平行于地面，旋转不改变中心、尺寸或离地高度。
- 保留稳定的家具根节点与模型居中结构；移动和旋转不回写新的 size 数组，避免触发模型重新克隆和包围盒计算。
- 拖动期间保留对象选中状态，避免点击旋转环被 Canvas 当作空白点击。松手后将 rotation 保存到 Zustand，Play 高模沿用同一姿态。
- Edit 低模、拖放盒体预览、Play 高模的三层渲染策略保留。

## 验证

- `npm run build` 通过，TypeScript/Vite 无编译错误。保留现有 Three.js 主包体积提示。
- `npm run verify:rotation` 通过。测试直接调用真实 TransformControls 的射线拾取、pointerDown、pointerMove 和 pointerUp：4 个相机角度共 24 次拖环，验证中心、高度、尺寸、底面水平与释放前后姿态一致。
- 验证 4 圈角度连续性，包括跨越正负 pi 边界；验证带俯仰/滚转的输入姿态被约束为水平姿态。
- 内置浏览器可用实例列表为空，未进行页面截图或真实浏览器鼠标验收。以上控件测试在 Node.js 24 环境运行。
