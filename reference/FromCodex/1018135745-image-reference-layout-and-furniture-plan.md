# 参考户型重建与家具规划

本次示例户型已经按你提供的户型图重建为固定模板 `three-bedroom-two-bath-v6`。这是确定性几何，不调用外部 AI，也不生成家具实体。

## 户型结果

- 坐标：米制、右手系、Y 轴向上；规划位置使用 `[x, y, z]`，`+Z` 作为北向。
- 建筑轮廓：18 个转角，整体为带上下阳台和左侧凹口的错位轮廓，不是矩形。
- 建筑面积：约 `115.66 m²`。
- 房间：客餐厅、主卧、两个次卧、公共卫生间、主卧套卫、厨房、中部过厅、北侧封闭阳台、南侧封闭阳台。
- 结构：99 块不重叠墙体，所有墙板正面、反面、窄侧面使用独立 surface ID；10 个房间各自拥有独立地板和顶面。
- 开口：11 个门洞，14 个窗/玻璃面。两个阳台各有三面玻璃围合；卧室、厨房和卫生间均有对应窗洞，过厅不设置窗户。
- Web 场景字段保持 `furniture: []`。家具规划只写入 `room.layout.furniturePlan`，不会在示例场景中加载模型或创建碰撞体。
- 当前规划共 29 个家具锚点；床头柜 A/B 在表格中合并为一行，场景元数据中仍是两个独立条目。
