# 平滑墙体透明、家具原框移除与漫游高度

## 实现结果

1. 恢复连续的 opacity 半透明，移除 Alpha Hash 噪点。保留 0.5s Cubic.Out 渐变、途中反向和 Play 立即恢复实墙。
2. 删除扫描家具的原始 Bounding Box 线框叠加，以及顶栏“原框对比”按钮。模型、编辑操作、尺寸数据、碰撞与拖放预览保留。当前扫描的 7 件家具均有低模和高模地址。
3. Play 的统一眼高常量由 1.7m 调整为 1.5m，出生点与每帧高度约束使用同一常量。

## 平滑透明的技术处理

难点是整面长墙或凹角墙按对象中心排序时，实际局部前后关系可能相反。之前的 Alpha Hash 绕开排序，但改变了半透明外观。

本次新增 MIT 开源依赖 [three-csg-ts](https://github.com/samalexander/three-csg-ts)，使用它已有的 BSP 平面划分与多边形拆分能力。墙体在几何变化时预处理一次；相机移动时只遍历树，为墙面片段指定从远到近的 renderOrder。各片段共享原墙的材质与动画透明度，保持标准 alpha blending；渐变终点不切换渲染队列或深度写入。

Edit 仅显示这些排序片段，Play 仅显示原始立方墙板，避免重复绘制。任务轮询若未改变几何，继续复用 BSP 与材质。忽略门洞切分产生的小于 0.01mm 的退化薄片。

当前扫描预处理后为 300 组墙面片段。代价是 Edit 的墙体绘制次数增加；Play 仍使用原始 30 个墙面板，家具低模/高模策略不变。运行时没有逐帧重建几何或更新 React 状态。
