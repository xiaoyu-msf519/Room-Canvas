# Pointer Lock 异常位移修复

## 结论

Pointer Lock 机制不会把隐藏指针限制在视口范围内；`movementX/Y` 是锁定期间的相对位移。当前跳变来自锁定建立、恢复、失焦或浏览器/设备上报的异常大相对位移。之前的实现将异常值截断后继续放入缓冲区，所以跳变变得平滑但仍然存在。

## 修复

- 请求 Pointer Lock 时优先使用 `unadjustedMovement: true`，旧浏览器自动回退到普通请求。
- 将异常增量阈值降为 48px，超过阈值的事件直接丢弃，不再进入视角缓冲。
- 将待处理缓冲限制为 64px，每帧最多消费 12px，避免单个异常事件形成可见镜头跳跃。
- 在锁定建立后清空旧输入并忽略 80ms 合成首帧。
- 处理 `pointerlockerror` 与窗口失焦，清空键盘和视角输入，避免恢复时沿用陈旧事件。
- 保留四类相对位移来源兼容：标准 `movementX/Y`、Firefox 和 WebKit 前缀字段。
